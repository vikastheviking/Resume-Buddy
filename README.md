> **Resume-Buddy** is a production-grade web application engineered to transform standard resumes into Fortune 500 ATS-optimized profiles scoring 95%+ compatibility against any target Job Description.

---

## ✨ Features

- **📄 Dual Input System**:
  - **Input Resume**: Live text editor + drag-and-drop file upload (`.pdf`, `.docx`, `.txt`) with instant text extraction.
  - **Job Description**: Live text editor + drag-and-drop file upload with automated keyword parsing.
- **📊 Hero ATS Metric Comparison**:
  - **Actual ATS Score**: Baseline score of the original unoptimized resume with visual progress bar.
  - **Score Boost Badge**: Real-time quantified lift indicator (e.g. `+75% Score Boost`).
  - **Updated ATS Score**: Verified 95%+ ATS-optimized score.
- **📑 Clean ATS Single-Column Result**:
  - Adheres to standard ATS parsing standards (no tables, no graphics, clear hierarchy).
  - Quantified STAR impact metrics generated by Llama-3.3-70B.
  - 1-Click Markdown copy to clipboard.
  - **📥 Download ATS PDF**: Generates a clean, ATS-compliant PDF.
  - **📄 Download ATS DOCX**: Generates an ATS-compliant Word document.
- **🔐 Advanced Email Authentication**:
  - **5-Layer Email Verification**: RFC 5322 syntax validation, global DNS MX lookup, disposable domain blacklist, typo detection, and direct live SMTP mailbox probe (`RCPT TO`).
  - **6-Digit OTP Flow**: Secure one-time password signup/signin with rate limiting and constant-time cryptographic verification.
  - **100% Free Live Email Delivery**: Seamless integration with your personal Gmail via Google App Passwords (500 free emails/day) or custom SMTP.
  - **🚀 Guest Evaluation Mode**: Instant 1-click demo access for presentations.

## 🚀 Quick Start

### 1. Clone the Repository
```bash
git clone https://github.com/vikastheviking/Resume-Buddy.git
cd Resume-Buddy
```

### 2. Install Dependencies
```bash
# Install Node.js dependencies
npm install

# Install Python dependencies
pip install -r requirements.txt
```

### 3. Configure Environment Variables
Copy the example environment file:
```bash
cp .env.example .env
```
Edit `.env` and set your Groq API key:
```env
GROQ_API_KEY=your_groq_api_key_here
```
*(Optional: For live OTP email delivery to real user inboxes, add your Gmail address and Google App Password).*

### 4. Start the Application
```bash
npm start
```

Visit **http://localhost:3000** in your browser!
